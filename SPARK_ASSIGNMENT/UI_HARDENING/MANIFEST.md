## Purpose
Isolated Spark work packet for functional hardening and user-acceptance testing of the existing PubCast UI.

This supersedes the earlier Spark tooling experiment **for this assignment only**. Do not mix the two scopes.

## Scope lock
The task is enhancement and verification of the existing UI, not redesign. Existing architecture, interaction concepts, styling, naming, and working components are presumptively retained. Make the smallest repairs supported by reproduced defects.

- SPARK_UI_HARDENING_PROMPT.md — authoritative assignment.

## Important limitation
This folder contains the relevant text sources available in the current NowCurtsey-Build/Spark branch. It does not pretend that every historical or binary PubCast artifact is canonical. Spark must not substitute donor/reference material for the current implementation.

If a required live UI file is referenced by the docs but absent from this packet, report the exact missing path/capability rather than reconstructing it from memory or redesigning around its absence.
